Friends Fitness Management System 💪

A Gym Management System built with Flutter using Clean Architecture principles. This app helps gym owners manage members, attendance, renewals, and authentication efficiently with Firebase as backend.

🚀 Features

🔐 Admin Authentication (Login & Forgot Password)

👥 Add, Update, Delete Members

🔄 Membership Renewal

📅 Attendance Tracking

📊 Dashboard with Statistics

🔎 Member Search

⚡ Real-time Firebase Integration

🧪 Unit Tested Core Features
